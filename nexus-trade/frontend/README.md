# Nexus Trade Frontend

## Prerequisites
- Node.js 20+
- npm

## Environment
Create `/home/runner/work/Nexus-Trade-/Nexus-Trade-/nexus-trade/frontend/.env`:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

## Run locally
```bash
cd /home/runner/work/Nexus-Trade-/Nexus-Trade-/nexus-trade/frontend
npm ci
npm run dev
```

## Build
```bash
npm run build
```

## Lint
```bash
npm run lint
```
